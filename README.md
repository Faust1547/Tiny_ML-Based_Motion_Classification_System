# Tiny ML-Based Motion Classification System

## Overview
本專案以 MPU6050 與 Arduino DUE 建立嵌入式動作辨識系統，透過 1D CNN 辨識上下、左右、旋轉與靜止等動作，並進一步針對嵌入式平台的記憶體使用量與推論延遲進行優化。
